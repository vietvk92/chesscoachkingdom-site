Questions fréquentes

Comment restaurer mes achats ?

Ouvrez Réglages → Plus → Restaurer. Connectez-vous avec le compte Apple utilisé pour l’achat.

Comment résilier mon abonnement ?

Apple gère les abonnements. Réglages → votre nom → Abonnements → Chess Coach Kingdom → Annuler.

Le Partage familial fonctionne-t-il ?

Cela dépend des réglages de votre abonnement sur l’App Store. Écrivez-nous en cas de problème.

Quelle différence entre le mode enfant et le mode adulte ?

Le mode enfant est chaleureux et ludique : Firefly encourage vos coups et les pièces réagissent subtilement sur l’échiquier. Le mode adulte est plus calme et met vos statistiques en avant. Le coach et les leçons sont les mêmes dans les deux.

Cela fonctionne-t-il hors ligne ?

Oui. Le moteur, le coach, vos parties et vos statistiques fonctionnent sur votre appareil : vous pouvez jouer et apprendre sans connexion.

Comment activer ou désactiver la voix ?

La voix du commentateur est facultative. Ouvrez Réglages dans l’app pour l’activer ou la désactiver, et utilisez le volume ou le commutateur silencieux de l’appareil comme d’habitude.

Comment fonctionnent les profils et le contrôle parental ?

Chaque joueur peut avoir son profil. Les zones réservées aux adultes, comme les achats, sont protégées par un contrôle parental.

Où sont stockées mes données ?

Uniquement sur votre appareil. Aucun compte, aucune donnée personnelle collectée.

Comment signaler un bug ?

Écrivez-nous en décrivant le problème, le modèle de votre appareil (ex. iPhone 15) et votre version d’iOS (Réglages → Général → Informations).
