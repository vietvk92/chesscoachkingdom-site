Questions fréquentes

Comment restaurer mes achats ?

Ouvrez Réglages → Plus → Restaurer. Connectez-vous avec le compte Apple utilisé pour l’achat.

Comment résilier mon abonnement ?

Apple gère les abonnements. Réglages → votre nom → Abonnements → Chess Coach Kingdom → Annuler.

Le Partage familial fonctionne-t-il ?

Cela dépend des réglages de votre abonnement sur l’App Store. Écrivez-nous en cas de problème.

Comment fonctionnent les profils et le contrôle parental ?

Chaque joueur peut avoir son profil. Les zones réservées aux adultes, comme les achats, sont protégées par un contrôle parental.

Où sont stockées mes données ?

Uniquement sur votre appareil. Aucun compte, aucune donnée personnelle collectée.

Comment signaler un bug ?

Écrivez-nous en décrivant le problème, le modèle de votre appareil (ex. iPhone 15) et votre version d’iOS (Réglages → Général → Informations).
